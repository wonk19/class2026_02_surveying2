연구배경 20점

  • 사회적·공공적 필요성을 객관적인 자료와 근거로 설득력 있게 제시하였는가?
  • 기존 지식이나 현황에서 무엇이 부족한지 구체적으로 설명하였는가?
  • 연구질문과 세부목적으로 이어지는 논리가 자연스럽고 개연성이 있는가?

연구질문 / 세부목적 20점

  • 연구질문이 명료하며 분석으로 답할 수 있도록 범위가 정해져 있는가?
  • 세부목적 3개가 구체적이고 측정 가능하며, 각 목적의 달성 여부를 판단할 수 있는가?
  • 각 목적이 연구질문에 답하는 데 필요하고 서로 중복 없이 논리적으로 연결되는가?

재료 / 방법 15점

  • 자료의 출처·관측 시기·공간 범위·해상도와 선정 이유가 명확한가?
  • 전처리와 분석 방법이 각 세부목적에 적합하며, 선택 근거와 가정을 설명하였는가?
  • 코드·설정·처리 순서를 재현할 수 있고, 결측·오차·품질 관리 방법이 제시되어 있는가?

연구결과 15점

  • 각 세부목적에 대응하는 분석 결과를 빠짐없이 제시하였는가?
  • 지도·그래프·표에 단위·범례·비교 기준을 명확히 표시하고 핵심 수치를 정확하게 설명하였는가?
  • 결과가 자료와 분석에서 확인된 사실에 근거하며, 관찰 사실과 해석을 구분하였는가?

토의 / 토론 / 해석 15점

  • 결과가 나타난 이유를 관련 지식과 자료에 근거해 설명하고 다른 가능한 해석도 검토하였는가?
  • 선행 연구·예상과의 일치 또는 차이, 불확실성·한계·일반화 범위를 논리적으로 논의하였는가?
  • 교수의 질문에 분석 근거로 답하고, 상관관계를 인과관계로 단정하거나 결과를 과장하지 않았는가?

결론 15점

  • 연구질문과 세부목적에 대한 답을 핵심 결과에 근거하여 명확하게 제시하였는가?
  • 연구의 사회적·공공적 의미와 활용 가능성을 연구 범위 안에서 정리하였는가?
  • 새로운 주장이나 미제시 결과를 추가하지 않고, 한계와 필요한 후속 연구를 간결하게 정리하였는가?
