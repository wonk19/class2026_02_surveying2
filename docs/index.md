> **이 보고서는 작성 방법을 보여주는 예시입니다.** 기본 분석 36개 표본과 심화 분석 384행의 별도 합성자료에 관계를 의도적으로 넣었습니다. 실제 부산의 온도나 Landsat 관측 결과로 해석하면 안 됩니다. 본문의 문장 구조를 참고하고, 자기 조의 실제 자료와 결과로 교체하세요.

## 01 연구 질문 {#question}

도시의 녹지는 지표면 온도와 어떤 관계가 있을까요? 이 프로젝트는 **“녹지 지표가 높은 표본에서 지표면 온도가 낮게 나타나는가?”**를 질문으로 삼습니다.

실제 연구라면 대상 지역과 관측 시기를 정하고 NDVI와 LST를 같은 공간·시간 기준으로 비교해야 합니다. 여기서는 분석 결과를 웹보고서에 연결하는 방법에 집중하기 위해 **합성 NDVI와 합성 LST**를 사용합니다.

- **설명 변수:** 합성 NDVI, 0.12–0.82
- **결과 변수:** 합성 LST, 단위 °C
- **표본 단위:** 위치와 관측 날짜가 없는 가상의 관측점 36개
- **기본 탐색:** 두 변수의 산점도와 집단별 평균 차이
- **이어지는 심화 질문:** 환경조건 보정, 계절별 차이, 품질 기준과 새 공간 블록에서의 검증(별도 합성자료 사용)

## 02 자료와 방법 {#method}

### 자료를 만든 방법

고정 난수 seed `2026`을 사용해 다음 식으로 자료를 만들었습니다.

```text
합성 LST = 37 − 11 × 합성 NDVI + 무작위 오차
```

따라서 음의 관계는 **실제 자료에서 새로 발견한 현상이 아니라 생성 과정에 넣은 조건**입니다. 이 점을 숨기지 않는 것이 예시 보고서의 가장 중요한 전제입니다.

### 분석 순서

1. 36개 가상 표본을 만들고 CSV로 저장합니다.
2. 산점도와 선형 적합선을 그립니다. Pearson 상관계수는 표본의 관계를 요약하는 값으로 사용합니다.
3. NDVI 0.45를 기준으로 두 집단을 나누어 평균 LST를 비교합니다. 0.45는 설명을 위한 임의 기준이며 보편적인 녹지 분류 기준이 아닙니다.
4. 같은 실행에서 만든 그림·수치·코드를 보고서에 연결합니다.

실제 Landsat 분석에서는 자료 ID, 지역, 기간, 구름·수면 제외 조건, 밴드 변환, 표본 추출·집계 방법을 이 절에 기록해야 합니다. 참고용 GEE 노트북은 한 장면의 LST 지도까지 다루며, 이 합성 결과를 실제 관측으로 검증한 것은 아닙니다.

### 심화 분석을 위한 별도 자료 {#advanced-data}

앞의 36개 표본은 기본 그래프 연습용입니다. 아래 세 분석은 **서로 같은 별도의 합성자료 384행**을 사용합니다. 서로 다른 자료의 계수를 직접 비교하지 않습니다.

- **구조:** 24개 가상 공간 블록 × 8개 지점 × 봄·여름 2회 = 192지점, 384행. 384개의 독립 지점이 아닙니다.
- **열:** `block`(공간 집단 번호), `site`(지점 번호), `summer`(봄=0, 여름=1), `ndvi`, `elevation_m`(m), `impervious`(불투수면 비율 0~1), `coast_km`(해안 거리 km), `valid_fraction`(가상의 유효 관측 비율 0~1), `lst_c`(°C).
- **의도한 조건:** NDVI가 높으면 고도도 높고 불투수면은 적어지도록 만들었습니다. 블록마다 공통 오차를 더해 같은 블록 내 관측이 서로 관련되도록 했습니다. 품질이 낮을수록 관측 오차가 커집니다.
- **생성식:** `LST = 28 + 7×summer − (4+5×summer)×NDVI − 0.006×고도 + 3×불투수면비율 − 0.12×해안거리 + 블록오차 + 관측오차`. seed는 `20261026`입니다. 모든 계수는 교육 목적으로 정한 가정입니다.

**불확실성 계산:** 24개 블록을 복원추출하고, 선택된 블록에 속한 모든 지점·계절을 함께 가져와 모델을 다시 적합합니다. 이를 600회 반복한 추정값의 2.5·97.5 백분위수를 95% 구간으로 표시했습니다. 블록 간 독립성과 현재 모델·표본 구성을 전제로 한 근사 구간입니다. 개별 행을 독립으로 간주한 구간도, 인과효과를 보증하는 구간도 아닙니다.

### 심화 1 · 다른 환경조건을 보정해도 관계가 남는가? {#deep-confounding}

**왜 더 분석하나요?** 녹지가 많은 곳이 동시에 고도가 높고 불투수면이 적다면, 단순한 온도 차이를 모두 녹지의 영향으로 설명할 수 없습니다.

**방법.** 계절과 NDVI를 넣은 선형회귀 모델에 고도·불투수면 비율·해안 거리를 추가해 NDVI 계수의 변화를 비교했습니다. 여기서는 두 계절의 NDVI 기울기가 같다고 가정합니다. 이는 다음 심화 분석에서 재검토할 가정입니다.

```text
모델 A: LST ~ NDVI + 계절
모델 B: LST ~ NDVI + 계절 + 고도 + 불투수면비율 + 해안거리
```

![그림 3. 환경조건 보정 전후 NDVI 계수와 보정 모델의 잔차.](figures/deep_confounding.png)

**그림 3.** 왼쪽은 NDVI 0.1 증가당 계수와 블록 bootstrap 95% 구간, 오른쪽은 모델 B의 예측값과 잔차(관측값−예측값)입니다. 잔차의 곡선·부채꼴·집단별 패턴은 누락된 구조를 검토하는 단서입니다. 그림만으로 모델 적합성을 확정하지 않습니다.

**실행 결과.** 계절만 보정하면 **-1.12°C** (95% 구간 -1.25~-0.99°C), 환경조건을 추가하면 **-0.57°C** (95% 구간 -0.79~-0.37°C)입니다. 음의 관계는 남지만 크기는 줄었습니다.

**해석.** 이 합성자료에서는 단순한 관계에 다른 환경조건의 영향이 섞여 있습니다. 환경조건을 고려한 뒤에도 남는 관계를 따로 설명해야 합니다.

**한계와 다음 질문.** 보정한 변수 밖의 요인, 비선형성, 설명변수 간 상관은 여전히 문제입니다. 환경조건을 통제했다고 자동으로 인과효과가 되지는 않습니다. 두 계절의 관계가 정말 같은지도 아직 확인하지 않았습니다.

### 심화 2 · 봄과 여름에서 녹지–온도 관계가 같은가? {#deep-seasonality}

**질문.** 전체를 하나의 기울기로 요약하면 계절별 차이가 가려지지 않을까요?

**방법.** 모델 B에 `NDVI × summer` 교호작용 항을 추가했습니다. 봄의 기울기는 NDVI 계수, 여름의 기울기는 NDVI 계수와 교호작용 계수의 합입니다. 두 기울기의 차이는 각 bootstrap 반복 안에서 구하므로 추정값 사이의 관련성도 반영합니다.

```text
모델 C: LST ~ NDVI + 계절 + NDVI×계절 + 고도 + 불투수면비율 + 해안거리
봄 기울기 = β_NDVI
여름 기울기 = β_NDVI + β_NDVI×여름
```

![그림 4. 평균 환경조건에서의 계절별 예측선과 봄·여름·차이의 계수 구간.](figures/deep_seasonality.png)

**그림 4.** 왼쪽은 고도·불투수면·해안 거리를 전체 평균으로 고정한 예측선입니다. 두 계절의 NDVI 관측 범위가 겹치는 구간에만 그렸으며 개별 지점의 관측 온도가 아닙니다. 오른쪽은 NDVI 0.1 증가당 봄·여름 계수와 그 차이의 95% 구간입니다.

**실행 결과.** 봄은 **-0.34°C** (95% 구간 -0.60~-0.10°C), 여름은 **-0.81°C** (95% 구간 -1.01~-0.63°C)입니다. 여름−봄의 기울기 차이는 **-0.47°C** (95% 구간 -0.64~-0.31°C)입니다.

**해석.** 이 합성 표본에서는 여름의 음의 관계가 더 큽니다. 차이의 구간이 0을 포함하지 않는 것은 이 모델·합성 표본에서 계절 차이를 지지하는 근거입니다. 생성식에 넣은 계절 차이를 분석이 포착한 것이며 현실에서 새로 발견한 현상이 아닙니다.

**한계와 다음 질문.** 봄·여름 두 시점만으로 연중 변화나 장기 추세를 설명할 수 없습니다. 실제 자료에서는 계절별 구름·관측일·표본 구성도 확인해야 합니다. 품질 필터를 바꾸거나 관측하지 않은 지역을 예측하면 결과가 유지될지도 검토합니다.

### 심화 3 · 분석 조건과 평가 지역을 바꿔도 유지되는가? {#deep-robustness}

**질문.** 특정 품질 기준에만 의존한 결론인가요? 이미 본 지점에서 잘 맞는 모델이 새로운 공간 블록에도 적용될까요?

**방법 A — 민감도 분석.** 유효 관측 비율 필터 없음·0.5 이상·0.7 이상으로 모델 C를 다시 적합했습니다. 같은 계절별 모형과 블록 bootstrap을 사용했습니다. 0.5와 0.7은 예시 기준이며 Landsat 공식 권장 기준이 아닙니다. 가장 유리한 기준만 선택하지 않고 세 결과를 함께 보고합니다.

![그림 5. 품질 기준별 여름 기울기와 공간 블록 교차검증 오차.](figures/deep_robustness.png)

**그림 5 왼쪽의 실행 결과.** 필터가 엄격해지면 표본은 **384 → 278 → 182행**으로 줄고, 여름 기울기는 **−0.81 → −0.82 → −0.87°C/NDVI 0.1**입니다. 95% 구간은 순서대로 **−1.01~−0.63, −1.03~−0.62, −1.14~−0.65°C**입니다. 모두 24개 블록이 남았습니다. 봄 기울기와 계절 차이의 수치도 JSON에 함께 저장했습니다.

**해석 A.** 이 자료에서는 세 기준에서 방향이 유지됩니다. 그러나 엄격한 필터가 반드시 더 좁은 구간을 주지는 않습니다. 더 적은 표본을 사용하는 대가가 있기 때문입니다. 실제 구름 결측이 특정 계절·지역에 집중되면 이 합성 예시보다 선택 편향이 클 수 있습니다.

**방법 B — 공간 블록 교차검증.** 24개 블록을 6개 fold로 나누어 매회 4개 블록 전체를 평가용으로 남겼습니다. 같은 지점의 두 계절은 같은 fold에 들어갑니다. 나머지 20개 블록으로 학습해 평가 블록을 예측하고, 모든 관측이 한 번씩 평가된 오차를 합쳐 RMSE를 계산했습니다. 낮을수록 예측 오차가 작습니다.

- 기준 모델: 계절 + 고도 + 불투수면비율 + 해안거리.
- 확장 모델: 기준 모델 + NDVI + NDVI×계절.
- 두 모델에 동일한 fold를 사용했습니다. 임의 행 분할도 비교용으로 계산했지만, 같은 공간 집단이 학습·평가에 섞이는 이 결과를 새 지역 성능으로 해석하지 않습니다.

**그림 5 오른쪽의 실행 결과.** 블록 분할 RMSE는 기준 모델 **1.91°C**, 확장 모델 **1.81°C**입니다. NDVI와 교호작용을 추가한 개선은 약 **0.10°C**입니다. 확장 모델의 임의 행 분할 RMSE는 **1.74°C**였습니다. 이 비교는 품질 필터를 적용하기 전의 384행에서 수행했습니다.

**해석 B.** 이 자료에서 NDVI를 추가하면 새 블록 예측이 개선되지만, 개선 폭은 약 0.10°C로 크지 않습니다. 계수의 구간이 0을 포함하지 않는다는 사실과 예측에 실질적인 도움이 된다는 판단은 다릅니다.

**한계.** 이 블록들은 좌표가 없는 가상 집단입니다. 실제 공간 자기상관의 거리나 타 도시 일반화 성능을 검증한 것이 아닙니다. 실제 분석에서는 블록 크기·완충 거리·관측 날짜를 고려해야 합니다. 6-fold 단일 분할의 결과이며 성능 차이의 유의성 검정을 하지 않았습니다. 새로운 연도의 예측에는 시간 분할 검증도 필요합니다. 민감도 분석 역시 세 기준 밖의 모든 조건에 대한 강건성을 보장하지 않습니다.

## 04 논의와 한계 {#discussion}

이 예시에서 확인한 것은 **설정한 관계가 분석과 그림에 일관되게 나타났다는 사실**입니다. 현실의 도시 환경에 대한 새로운 결론은 아닙니다.

실제 프로젝트로 확장할 때는 다음을 검토해야 합니다.

- **공간·시간 일치:** NDVI와 LST가 같은 시점과 같은 공간 단위를 비교하는가?
- **관측 편향:** 구름을 제거하고 남은 날짜와 위치가 전체 지역·계절을 대표하는가?
- **표본 독립성:** 가까운 픽셀을 독립 표본처럼 취급하지 않았는가?
- **다른 설명 변수:** 고도, 해안 거리, 토지피복 등이 관계에 영향을 주지 않는가?
- **온도의 의미:** 위성의 지표면 온도를 기온이나 하루 평균 온도로 해석하지 않았는가?

각 조는 자기 자료에 해당하는 한계를 골라 **결과에 어떤 영향을 줄 수 있는지** 설명해야 합니다.

## 05 결론 {#conclusion}

합성자료 36개에서는 높은 NDVI와 낮은 LST가 함께 나타났습니다. 이는 의도한 생성식과 일치하며, 실제 녹지의 냉각 효과를 입증하지는 않습니다.

심화 분석에서는 환경조건 보정으로 관계의 크기가 달라지고, 계절별 기울기가 다르며, 품질 기준을 바꿔도 방향이 유지됨을 확인했습니다. 새 블록 예측에서 NDVI 추가의 개선은 약 0.10°C였습니다. 모두 합성자료와 설정한 모델 안에서의 결과입니다.
