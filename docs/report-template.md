## 03 분석 결과 {#results}
### 핵심 결과 1
그림을 figures 폴더에 올린 뒤 다음 문법으로 연결합니다.

```markdown
![그림 1. 대상과 단위](figures/my_figure.png)
```

관찰한 사실, 수치, 가능한 해석과 한계를 순서대로 씁니다. 그림 생성 노트북도 연결합니다.

### 확장 질문 1 · 다른 설명을 고려했는가?
기본 결과를 설명할 수 있는 다른 요인을 정하고, 보정 전후 수치·그림·해석·한계를 씁니다.

### 확장 질문 2 · 언제, 어디에서 관계가 달라지는가?
계절·토지피복·지역 등의 차이를 자료에 맞게 검토합니다. 집단별 표본과 불확실성을 함께 기록합니다.

### 검증 · 조건을 바꾸어도 결과가 유지되는가?
품질 필터·공간 해상도·기간 등의 민감도를 검토하고, 예측 목적이라면 학습에 쓰지 않은 공간·시간 자료로 기준 모델과 비교합니다. 효과가 작거나 방향이 바뀐 결과도 숨기지 않습니다. 위 세 제목은 예시이며 연구 질문에 맞게 바꿉니다.
